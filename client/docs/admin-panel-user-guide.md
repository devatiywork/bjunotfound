# Административная панель - Руководство пользователя

## Доступ к панели

Административная панель доступна только пользователям с ролью **Администратор**.

### Как получить доступ:

1. Войдите в систему под учетной записью администратора
2. Перейдите в **Профиль** (кнопка в шапке сайта)
3. Переключитесь на вкладку **Администрирование**

## Управление пользователями

### Статистика

В верхней части страницы отображаются карточки со статистикой:

- **Всего пользователей** - общее количество зарегистрированных пользователей
- **Администраторов** - количество пользователей с правами администратора
- **Обычных пользователей** - количество пользователей без административных прав

### Поиск пользователей

Используйте строку поиска для быстрого поиска пользователя по email.

### Таблица пользователей

#### Колонки:

- **Email** - адрес электронной почты
- **Роль** - текущая роль пользователя (админ/пользователь)
- **Дата регистрации** - когда пользователь зарегистрировался
- **Записей веса** - количество записей веса
- **Целей** - количество активных и завершенных целей

#### Действия с пользователем:

**👁️ Просмотр**

- Открывает детальную информацию о пользователе
- Показывает основные данные, настройки калорийности
- Отображает последние записи веса и активные цели
- Статистику использования приложения

**🛡️ Изменить роль**

- Позволяет изменить роль пользователя
- Доступны все существующие роли системы
- При понижении администратора выводится предупреждение
- После изменения роль обновляется немедленно

**🗑️ Удалить**

- Удаляет пользователя и **ВСЕ** его данные безвозвратно
- Требует подтверждение через ввод email
- Удаляются:
  - Все записи веса
  - Все цели (активные и завершенные)
  - Планы питания
  - Прочие данные пользователя

⚠️ **Внимание:** Удаление пользователя необратимо!

### Пагинация

- Используйте стрелки навигации внизу таблицы
- Отображается по 20 пользователей на странице
- Показывается текущий диапазон и общее количество

## Настройки системы

### Категории настроек

#### 1. Границы безопасности

Минимальные и максимальные значения калорий для безопасности пользователей:

- **Минимальные калории для женщин** (по умолчанию: 1200 ккал)
  - Нижний порог калорий в день для женщин
- **Минимальные калории для мужчин** (по умолчанию: 1500 ккал)
  - Нижний порог калорий в день для мужчин
- **Максимальный дефицит калорий** (по умолчанию: 1000 ккал)
  - Максимальный допустимый дефицит в день при похудении
- **Максимальный профицит калорий** (по умолчанию: 500 ккал)
  - Максимальный допустимый профицит в день при наборе массы

#### 2. Темпы похудения

Предустановленные темпы для целей похудения:

- Очень быстрый (1 кг/неделю)
- Быстрый (0.75 кг/неделю)
- Умеренный (0.5 кг/неделю) - **рекомендуется**
- Комфортный (0.25 кг/неделю)

#### 3. Темпы набора массы

Предустановленные темпы для целей набора веса:

- Быстрый (0.5 кг/неделю)
- Умеренный (0.35 кг/неделю) - **рекомендуется**
- Комфортный (0.25 кг/неделю)

#### 4. Константы

Системные константы для расчетов:

- **Калорий в 1 кг жира** (по умолчанию: 7700 ккал)
  - Используется для расчета дефицита/профицита

### Изменение настроек

1. Откройте нужную категорию (кликните на заголовок)
2. Найдите настройку, которую хотите изменить
3. Введите новое значение в поле
4. Нажмите кнопку **Сохранить**
5. Появится уведомление об успешном сохранении

⚠️ **Важно:** При изменении настроек автоматически инвалидируется кэш, изменения применяются немедленно для всех пользователей.

### Сброс настроек

Кнопка **Сбросить все** в правом верхнем углу:

- Возвращает **все** настройки к значениям по умолчанию
- Требует подтверждение
- Изменения необратимы
- Используйте с осторожностью!

## Уведомления

Система автоматически показывает уведомления:

- ✅ **Успех** (зеленый) - операция выполнена успешно
- ❌ **Ошибка** (красный) - произошла ошибка
- ⚠️ **Предупреждение** (желтый) - важная информация
- ℹ️ **Информация** (синий) - общая информация

Уведомления автоматически исчезают через 5 секунд или их можно закрыть вручную.

## Советы по использованию

### Управление пользователями

- Регулярно проверяйте список пользователей на наличие неактивных аккаунтов
- Будьте осторожны при удалении пользователей - данные не восстановить
- Понижение прав администратора необратимо, сначала убедитесь в правильности действия

### Настройки калорийности

- Не устанавливайте слишком низкие минимальные калории - это опасно для здоровья
- Изменяйте темпы похудения/набора только после консультации со специалистом
- Константа калорий в жире не должна изменяться без весомых причин

### Безопасность

- Не сообщайте учетные данные администратора третьим лицам
- Регулярно проверяйте список администраторов
- При подозрении на компрометацию учетной записи немедленно измените пароль

## Устранение неполадок

### Не отображается вкладка "Администрирование"

- Убедитесь, что вы авторизованы как администратор
- Попробуйте перезагрузить страницу
- Проверьте подключение к интернету

### Ошибка при загрузке данных

- Проверьте подключение к интернету
- Обновите страницу (F5)
- Если ошибка повторяется - обратитесь к техподдержке

### Изменения не применяются

- Убедитесь, что нажали кнопку "Сохранить"
- Проверьте наличие уведомления об успехе
- Обновите страницу и проверьте снова

## Контакты

При возникновении вопросов или проблем с административной панелью обратитесь к техническому администратору системы.
