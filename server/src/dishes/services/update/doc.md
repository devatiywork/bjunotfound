# Update Dish Service - Документация

## UpdateDishService

**Файл:** `update-dish.service.ts`

**Назначение:** Обновление блюда с автоматическим пересчетом КБЖУ при изменении ингредиентов или порций.

### Метод: `execute(id: string, dto: UpdateDishDto, userId: string, isAdmin: boolean)`

**Описание:**
Обновляет данные блюда. При изменении ингредиентов или количества порций автоматически пересчитывает КБЖУ, цену и значения на порцию. Только создатель или админ могут редактировать блюдо.

**Параметры:**

- `id` (string) - UUID блюда для обновления
- `dto` (UpdateDishDto) - Данные для обновления (все поля опциональны):
  - `name?` (string) - Новое название
  - `description?` (string) - Новое описание
  - `servings?` (number) - Новое количество порций
  - `servingSize?` (number) - Новый размер порции
  - `cookingTimeMinutes?` (number) - Новое время приготовления
  - `difficulty?` (DifficultyLevel) - Новая сложность
  - `mealType?` (MealType) - Новый тип приема пищи
  - `cuisineType?` (CuisineType) - Новый тип кухни
  - `dishCategory?` (DishCategory) - Новая категория
  - `instructions?` (string) - Новые инструкции
  - `photo?` (string) - Новое фото
  - `isPublic?` (boolean) - Изменение видимости
  - `ingredients?` (AddIngredientDto[]) - Новый список ингредиентов
  - `tagIds?` (string[]) - Новый список тегов
- `userId` (string) - ID текущего пользователя
- `isAdmin` (boolean) - Является ли пользователь админом

**Возвращаемое значение:**
Обновленное блюдо со всеми связями (creator, ingredients, tags).

**Логика работы:**

1. **Проверка существования и прав:**
   - Ищет блюдо по ID
   - Выбрасывает `NotFoundException` если не найдено
   - Проверяет права: только создатель или админ
   - Выбрасывает `ForbiddenException` если нет прав

2. **Валидация ингредиентов (если обновляются):**
   - Проверяет минимум 1 ингредиент
   - Проверяет существование всех продуктов

3. **Валидация тегов (если обновляются):**
   - Проверяет существование всех тегов

4. **Пересчет КБЖУ (если изменились ингредиенты или порции):**
   - Определяет финальные ингредиенты (новые или старые)
   - Определяет финальное кол-во порций (новое или старое)
   - Вызывает CalculateNutritionService
   - Рассчитывает значения на порцию
   - Формирует nutritionUpdate объект

5. **Обновление в БД:**
   - Обновляет основные поля блюда
   - Обновляет КБЖУ (если был пересчет)
   - Если ingredients обновляются:
     - Удаляет старые связи (deleteMany)
     - Создает новые связи (create)
   - Если tagIds обновляются:
     - Удаляет старые связи (deleteMany)
     - Создает новые связи (create)

**Исключения:**

- `NotFoundException` - блюдо не найдено
- `ForbiddenException` - недостаточно прав для редактирования
- `BadRequestException` - блюдо без ингредиентов
- `BadRequestException` - один или несколько продуктов не найдены
- `BadRequestException` - один или несколько тегов не найдены

**Особенности:**

- **Частичное обновление:** Можно обновить только нужные поля
- **Автоматический пересчет:** КБЖУ пересчитывается только при изменении ингредиентов/порций
- **Персональные цены:** Использует цены текущего пользователя (userId)
- **Замена связей:** Ингредиенты и теги полностью заменяются (не добавляются)

**Пример использования:**

```typescript
// Изменение названия и описания (пересчета нет)
const updated = await updateDishService.execute(
  'dish-uuid',
  {
    name: 'Куриный салат Цезарь (улучшенный)',
    description: 'Классический салат с авторским соусом',
  },
  'user-uuid',
  false,
);

// Изменение количества порций (пересчет на порцию)
const updated = await updateDishService.execute(
  'dish-uuid',
  {
    servings: 4, // было 2
  },
  'user-uuid',
  false,
);
// caloriesPerServing пересчитается: totalCalories / 4

// Изменение ингредиентов (полный пересчет)
const updated = await updateDishService.execute(
  'dish-uuid',
  {
    ingredients: [
      { productId: 'chicken-breast-id', amount: 250, unit: 'G' }, // было 200
      { productId: 'lettuce-id', amount: 100, unit: 'G' },
      { productId: 'caesar-dressing-id', amount: 60, unit: 'ML' }, // было 50
    ],
  },
  'user-uuid',
  false,
);
// Пересчет: totalCalories, totalProteins, totalPrice, etc.

// Попытка редактировать чужое блюдо (не админ)
try {
  await updateDishService.execute(
    'someone-dish-uuid',
    { name: 'Хакнутое название' },
    'user-uuid',
    false,
  );
} catch (error) {
  // ForbiddenException: Недостаточно прав для редактирования
}
```

**Применение:**

- Редактирование рецептов через UI
- Корректировка ингредиентов
- Изменение количества порций
- Обновление фото и описания
- Изменение видимости блюда (публичное/личное)

**Важно:**

- Ингредиенты и теги заменяются полностью, а не добавляются
- КБЖУ пересчитывается только при необходимости (оптимизация)
- Цены берутся из UserProductPrice текущего пользователя (не создателя)
