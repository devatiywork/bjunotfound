# Remove Dish Service - Документация

## RemoveDishService

**Файл:** `remove-dish.service.ts`

**Назначение:** Удаление блюда из системы (физическое удаление).

### Метод: `execute(id: string, userId: string, isAdmin: boolean)`

**Описание:**
Удаляет блюдо из базы данных. Только создатель или админ могут удалить блюдо. При удалении каскадно удаляются все связи (ингредиенты, теги, избранное).

**Параметры:**

- `id` (string) - UUID блюда для удаления
- `userId` (string) - ID текущего пользователя
- `isAdmin` (boolean) - Является ли пользователь админом

**Возвращаемое значение:**
Объект с сообщением:

```typescript
{
  message: 'Блюдо успешно удалено';
}
```

**Логика работы:**

1. **Проверка существования:**
   - Ищет блюдо по ID
   - Выбрасывает `NotFoundException` если не найдено

2. **Проверка прав:**
   - Проверяет: `isAdmin OR dish.userId === userId`
   - Выбрасывает `ForbiddenException` если нет прав

3. **Удаление:**
   - Выполняет `prisma.dish.delete({ where: { id } })`
   - Prisma автоматически удаляет связанные записи:
     - DishIngredient (через onDelete: Cascade)
     - DishTagRelation (через onDelete: Cascade)
     - FavoriteDish (через onDelete: Cascade)

**Исключения:**

- `NotFoundException` - блюдо не найдено
- `ForbiddenException` - недостаточно прав для удаления

**Особенности:**

- **Физическое удаление:** Данные удаляются навсегда (нет soft delete)
- **Каскадное удаление:** Автоматически очищаются все связи
- **Админ-права:** Админ может удалить любое блюдо
- **Создатель:** Пользователь может удалить только свои блюда

**Пример использования:**

```typescript
// Удаление своего блюда
const result = await removeDishService.execute(
  'my-dish-uuid',
  'user-uuid',
  false,
);
// { message: 'Блюдо успешно удалено' }

// Админ удаляет чужое блюдо
const result = await removeDishService.execute(
  'someone-dish-uuid',
  'admin-uuid',
  true,
);
// { message: 'Блюдо успешно удалено' }

// Попытка удалить чужое блюдо (не админ)
try {
  await removeDishService.execute('someone-dish-uuid', 'user-uuid', false);
} catch (error) {
  // ForbiddenException: Недостаточно прав для удаления
}
```

**Применение:**

- Удаление устаревших рецептов
- Очистка тестовых данных
- Модерация контента (админ)
- Управление личными блюдами

**Важно:**

- Удаление необратимо - данные теряются навсегда
- Если блюдо в избранном у других пользователей - связи удаляются
- Рекомендуется подтверждение пользователя перед удалением в UI
