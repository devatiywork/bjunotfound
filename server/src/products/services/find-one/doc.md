# Find One Product Service - Документация

## FindOneProductService

**Файл:** `find-one-product.service.ts`

**Назначение:** Получение одного продукта по ID с проверкой прав доступа.

### Метод: `execute(id: string, userId?: string)`

**Описание:**
Возвращает полную информацию о продукте по его ID. Автоматически проверяет права доступа к приватным продуктам. Включает персональную цену пользователя, если userId передан.

**Параметры:**

- `id` (string) - UUID продукта
- `userId?` (string) - ID текущего пользователя (опционально)

**Возвращаемое значение:**
Объект продукта с полями:

- Все поля продукта (id, name, description, calories, proteins, fats, carbs, и т.д.)
- `category` - Полный объект категории
- `tags` - Массив связей тегов с полными объектами тегов
- `creator` - Объект создателя (id, email)
- `price` - Персональная цена пользователя (number или null)

**Логика работы:**

1. **Запрос продукта:**
   - Ищет продукт по ID
   - Включает все связанные данные: category, tags, creator
   - Если userId передан, включает userPrices для этого пользователя

2. **Проверка существования:**
   - Если продукт не найден, выбрасывает `NotFoundException`

3. **Проверка прав доступа:**
   - Если продукт приватный (`isPublic: false`) И userId не совпадает с userId продукта
   - Выбрасывает `ForbiddenException`

4. **Обработка цены:**
   - Добавляет поле `price` из userPrices[0].price или null
   - Удаляет служебное поле `userPrices` из ответа

**Исключения:**

- `NotFoundException` - продукт с указанным ID не найден
- `ForbiddenException` - доступ к приватному продукту запрещен (не владелец)

**Особенности:**

- **Контроль доступа:** Публичные продукты доступны всем, приватные - только владельцу
- **Персональные цены:** Автоматически загружаются для текущего пользователя
- **Полная информация:** Включает все связанные данные в одном запросе

**Пример использования:**

```typescript
// Получение публичного продукта (без авторизации)
const product = await findOneProductService.execute('product-uuid');

// Результат:
// {
//   id: 'product-uuid',
//   name: 'Куриная грудка',
//   isPublic: true,
//   category: { id, name, ... },
//   tags: [{ tag: { id, name, ... } }, ...],
//   creator: { id: 'creator-uuid', email: 'creator@example.com' },
//   price: null, // нет персональной цены
//   ...
// }
```

```typescript
// Получение продукта авторизованным пользователем
const product = await findOneProductService.execute(
  'product-uuid',
  'user-uuid',
);

// Результат с персональной ценой:
// {
//   id: 'product-uuid',
//   name: 'Куриная грудка',
//   price: 450, // персональная цена пользователя
//   ...
// }
```

```typescript
// Попытка доступа к чужому приватному продукту
try {
  await findOneProductService.execute(
    'private-product-uuid',
    'other-user-uuid',
  );
} catch (error) {
  // ForbiddenException: Доступ к этому продукту запрещен
}
```

**Использование в контексте:**

- Просмотр детальной информации о продукте
- Редактирование продукта (с дополнительной проверкой прав)
- Добавление продукта в рецепт/блюдо
- Сканирование штрих-кода и просмотр найденного продукта
