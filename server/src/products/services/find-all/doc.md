# Find All Products Service - Документация

## FindAllProductsService

**Файл:** `find-all-products.service.ts`

**Назначение:** Получение списка продуктов с продвинутой фильтрацией, пагинацией и сортировкой.

### Метод: `execute(filters: FilterProductsDto, userId?: string)`

**Описание:**
Возвращает отфильтрованный и отсортированный список продуктов с поддержкой пагинации. Автоматически фильтрует продукты по видимости (публичные + личные пользователя). Включает персональные цены пользователя в результат.

**Параметры:**

- `filters` (FilterProductsDto) - Фильтры и параметры пагинации:
  - `page?` (number) - Номер страницы (по умолчанию 1)
  - `limit?` (number) - Кол-во элементов на странице (по умолчанию 20, макс 100)
  - `search?` (string) - Поиск по названию, описанию, бренду (регистронезависимый)
  - `categoryId?` (string) - Фильтр по категории
  - `tagIds?` (string[]) - Фильтр по тегам (продукты с любым из указанных тегов)
  - `minCalories?` (number) - Минимальная калорийность
  - `maxCalories?` (number) - Максимальная калорийность
  - `minPrice?` (number) - Минимальная цена (только для авторизованных)
  - `maxPrice?` (number) - Максимальная цена (только для авторизованных)
  - `source?` (DataSource) - Фильтр по источнику (ADMIN/USER/API/IMPORT)
  - `isVerified?` (boolean) - Фильтр по верификации
  - `sortBy?` (string) - Поле сортировки: name, calories, price, createdAt (по умолчанию createdAt)
  - `sortOrder?` (string) - Порядок сортировки: asc, desc (по умолчанию desc)
- `userId?` (string) - ID текущего пользователя (опционально)

**Возвращаемое значение:**
Объект с полями:

- `products` - Массив продуктов с полной информацией:
  - Все поля продукта
  - `category` - Объект категории
  - `tags` - Массив связей тегов
  - `creator` - Объект создателя (id, email)
  - `price` - Персональная цена пользователя (number или null)
- `pagination` - Объект пагинации:
  - `total` - Общее кол-во продуктов
  - `page` - Текущая страница
  - `limit` - Кол-во элементов на странице
  - `totalPages` - Общее кол-во страниц

**Логика работы:**

1. **Подготовка параметров:**
   - Вычисляет `skip` и `take` для пагинации
   - Ограничивает `limit` до 100 элементов

2. **Построение условий фильтрации (AND-логика):**
   - **Видимость:** Публичные продукты ИЛИ личные продукты пользователя (если userId передан)
   - **Поиск:** По названию, описанию, бренду (регистронезависимый, LIKE)
   - **Категория:** Точное совпадение categoryId
   - **Теги:** Продукты, имеющие хотя бы один из указанных тегов
   - **Калории:** Диапазон minCalories - maxCalories
   - **Цена:** Фильтр по userPrices (только для авторизованных пользователей)
   - **Источник:** Точное совпадение source
   - **Верификация:** Точное совпадение isVerified

3. **Запрос к БД:**
   - Выполняет параллельно:
     - Получение продуктов с фильтрами, пагинацией, сортировкой, включением связей
     - Подсчет общего кол-ва продуктов с теми же фильтрами
   - Включает userPrices только если userId передан

4. **Обработка результатов:**
   - Добавляет поле `price` в каждый продукт:
     - Берет из userPrices[0].price если есть
     - Иначе null
   - Удаляет userPrices из ответа (служебное поле)

5. **Формирование пагинации:**
   - Вычисляет totalPages = ceil(total / limit)

**Особенности:**

- **Безопасность видимости:** Неавторизованные видят только публичные продукты, авторизованные + свои приватные
- **Фильтр по цене:** Работает только для авторизованных пользователей через связь userPrices
- **Оптимизация:** Параллельное выполнение count и findMany
- **Ограничение limit:** Максимум 100 элементов на странице для защиты от перегрузки
- **Комбинированный поиск:** Поиск по нескольким полям одновременно (OR-логика внутри AND)

**Пример использования:**

```typescript
const result = await findAllProductsService.execute(
  {
    page: 1,
    limit: 20,
    search: 'курица',
    categoryId: 'meat-category-id',
    tagIds: ['high-protein-tag'],
    minCalories: 100,
    maxCalories: 200,
    minPrice: 300,
    maxPrice: 600,
    isVerified: true,
    sortBy: 'calories',
    sortOrder: 'asc',
  },
  'user-uuid',
);

// Результат:
// {
//   products: [
//     {
//       id: 'uuid',
//       name: 'Куриная грудка',
//       calories: 165,
//       price: 450,
//       category: { ... },
//       tags: [...],
//       creator: { ... },
//       ...
//     },
//     ...
//   ],
//   pagination: {
//     total: 15,
//     page: 1,
//     limit: 20,
//     totalPages: 1
//   }
// }
```

**Использование без фильтров:**

```typescript
// Получить первые 20 публичных продуктов
const result = await findAllProductsService.execute({});

// Получить свои продукты
const result = await findAllProductsService.execute({}, 'user-uuid');
```
