# Update Product Service - Документация

## UpdateProductService

**Файл:** `update-product.service.ts`

**Назначение:** Обновление существующего продукта с валидацией данных и прав доступа.

### Метод: `execute(id: string, userId: string, dto: UpdateProductDto, isAdmin: boolean)`

**Описание:**
Обновляет данные существующего продукта с полной валидацией. Проверяет права доступа (только владелец или админ). Поддерживает обновление персональной цены пользователя. Позволяет частичное обновление (все поля опциональны).

**Параметры:**

- `id` (string) - UUID продукта для обновления
- `userId` (string) - ID текущего пользователя
- `dto` (UpdateProductDto) - Данные для обновления (все поля опциональны):
  - `name?` (string) - Новое название
  - `description?` (string) - Новое описание
  - `categoryId?` (string) - Новая категория
  - `tagIds?` (string[]) - Новый набор тегов (полная замена)
  - `calories?` (number) - Новая калорийность
  - `proteins?` (number) - Новое кол-во белков
  - `fats?` (number) - Новое кол-во жиров
  - `carbs?` (number) - Новое кол-во углеводов
  - `fiber?` (number) - Клетчатка
  - `sugar?` (number) - Сахар
  - `saturatedFats?` (number) - Насыщенные жиры
  - `sodium?` (number) - Натрий
  - `servingSize?` (number) - Размер порции
  - `unit?` (UnitType) - Единица измерения
  - `barcode?` (string) - Новый штрих-код
  - `brand?` (string) - Бренд
  - `photo?` (string) - URL фото
  - `price?` (number) - Новая персональная цена
  - `isPublic?` (boolean) - Видимость
- `isAdmin` (boolean) - Флаг администратора

**Возвращаемое значение:**
Обновленный продукт со всеми связями:

- Все обновленные поля продукта
- `category` - Объект категории
- `tags` - Массив связей тегов
- `creator` - Объект создателя
- `price` - Актуальная персональная цена пользователя

**Логика работы:**

1. **Проверка существования:**
   - Ищет продукт по ID
   - Выбрасывает `NotFoundException` если не найден

2. **Проверка прав доступа:**
   - Если не админ И userId не совпадает с userId продукта
   - Выбрасывает `ForbiddenException`

3. **Валидация категории (если обновляется):**
   - Если передан `categoryId`, проверяет существование категории
   - Выбрасывает `BadRequestException` если не найдена

4. **Валидация тегов (если обновляются):**
   - Если передан `tagIds`, проверяет существование всех тегов
   - Выбрасывает `BadRequestException` если хотя бы один не найден

5. **Валидация штрих-кода (если обновляется):**
   - Если передан `barcode` И он отличается от текущего
   - Проверяет уникальность нового штрих-кода
   - Выбрасывает `BadRequestException` если занят

6. **Обновление продукта:**
   - Извлекает `tagIds` и `price` из DTO
   - Обновляет остальные поля
   - Если `tagIds` передан:
     - Удаляет все старые связи тегов
     - Создает новые связи с переданными тегами

7. **Обновление персональной цены:**
   - Если `price` передана:
     - Ищет существующую запись в UserProductPrice
     - Если найдена - обновляет цену
     - Если не найдена - создает новую запись

8. **Получение актуальной цены:**
   - Запрашивает текущую цену пользователя из UserProductPrice
   - Добавляет в ответ

**Исключения:**

- `NotFoundException` - продукт не найден
- `ForbiddenException` - недостаточно прав для редактирования (не владелец и не админ)
- `BadRequestException` - категория не найдена
- `BadRequestException` - один или несколько тегов не найдены
- `BadRequestException` - продукт с таким штрих-кодом уже существует

**Особенности:**

- **Частичное обновление:** Можно передать только измененные поля
- **Полная замена тегов:** При передаче tagIds старые теги полностью заменяются новыми
- **Upsert цены:** Автоматически создает или обновляет персональную цену
- **Права доступа:** Владелец может редактировать свой продукт, админ - любой
- **Валидация:** Все изменяемые ссылочные данные валидируются

**Пример использования:**

```typescript
// Обновление основных полей
const updated = await updateProductService.execute(
  'product-uuid',
  'user-uuid',
  {
    name: 'Куриная грудка (обновленное название)',
    calories: 170, // скорректировали калорийность
    price: 480, // обновили цену
  },
  false,
);
```

```typescript
// Замена категории и тегов
const updated = await updateProductService.execute(
  'product-uuid',
  'user-uuid',
  {
    categoryId: 'new-category-id',
    tagIds: ['tag1', 'tag2', 'tag3'], // полная замена тегов
  },
  false,
);
```

```typescript
// Изменение штрих-кода
const updated = await updateProductService.execute(
  'product-uuid',
  'user-uuid',
  {
    barcode: '9876543210987', // новый уникальный штрих-код
  },
  false,
);
```

```typescript
// Админ обновляет чужой продукт
const updated = await updateProductService.execute(
  'other-user-product-uuid',
  'admin-uuid',
  {
    isVerified: true, // верифицирует продукт
    description: 'Исправлено описание',
  },
  true, // isAdmin
);
```

```typescript
// Попытка обновления без прав
try {
  await updateProductService.execute(
    'other-user-product-uuid',
    'user-uuid',
    { name: 'Новое название' },
    false,
  );
} catch (error) {
  // ForbiddenException: Недостаточно прав для редактирования
}
```
