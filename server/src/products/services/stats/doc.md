# Get Stats Service - Документация

## GetStatsService

**Файл:** `get-stats.service.ts`

**Назначение:** Получение статистики по всем продуктам в системе (только для администраторов).

### Метод: `execute()`

**Описание:**
Возвращает агрегированную статистику по продуктам в системе. Используется для админ-панели и мониторинга качества базы данных продуктов. Все запросы выполняются параллельно для оптимизации производительности.

**Параметры:**
Метод не принимает параметров.

**Возвращаемое значение:**
Объект со статистикой:

```typescript
{
  total: number,                    // Общее кол-во продуктов
  bySource: Array<{                 // Распределение по источникам
    source: DataSource,             // ADMIN | USER | API | IMPORT
    _count: number
  }>,
  topCategories: Array<{            // Топ-5 популярных категорий
    categoryId: string,
    _count: number
  }>,
  recentlyAdded: number            // Добавлено за последние 7 дней
}
```

**Логика работы:**

1. **Параллельное выполнение запросов:**
   Использует `Promise.all` для одновременного выполнения 4 запросов:

   a. **Общее количество продуктов:**
   - `this.prisma.product.count()`
   - Подсчитывает все продукты в БД

   b. **Группировка по источникам:**
   - `groupBy({ by: ['source'], _count: true })`
   - Показывает распределение: сколько продуктов от админов, пользователей, API, импорта

   c. **Топ-5 категорий:**
   - `groupBy({ by: ['categoryId'], _count: true })`
   - Сортировка по убыванию количества
   - Возвращает 5 самых популярных категорий

   d. **Недавно добавленные:**
   - `count({ where: { createdAt: { gte: Date.now() - 7d } } })`
   - Подсчитывает продукты, добавленные за последние 7 дней

2. **Формирование результата:**
   - Деструктурирует результаты из Promise.all
   - Возвращает структурированный объект со статистикой

**Использование:**

Эта статистика используется администраторами для:

1. **Мониторинга роста базы:**
   - Отслеживание общего количества продуктов
   - Анализ темпов добавления (recentlyAdded)

2. **Контроля качества:**
   - Проверка соотношения верифицированных/неверифицированных продуктов
   - Анализ источников данных (ADMIN/USER/API/IMPORT)

3. **Оптимизации контента:**
   - Определение популярных категорий (topCategories)
   - Планирование наполнения слабо представленных категорий

4. **Аналитики:**
   - Отчеты о состоянии базы данных
   - Тренды добавления продуктов

**Пример использования:**

```typescript
const stats = await getStatsService.execute();

// Результат:
// {
//   total: 1523,
//   bySource: [
//     { source: 'ADMIN', _count: 856 },
//     { source: 'USER', _count: 542 },
//     { source: 'API', _count: 98 },
//     { source: 'IMPORT', _count: 27 }
//   ],
//   topCategories: [
//     { categoryId: 'meat-uuid', _count: 234 },
//     { categoryId: 'vegetables-uuid', _count: 198 },
//     { categoryId: 'fruits-uuid', _count: 176 },
//     { categoryId: 'dairy-uuid', _count: 145 },
//     { categoryId: 'grains-uuid', _count: 132 }
//   ],
//   recentlyAdded: 47
// }
```

**Использование в админ-панели:**

```typescript
// Получение статистики для дашборда
const stats = await getStatsService.execute();

// Отображение метрик
console.log(`Всего продуктов: ${stats.total}`);
console.log(`Добавлено за неделю: ${stats.recentlyAdded}`);
console.log(`Темп роста: ${(stats.recentlyAdded / 7).toFixed(1)} в день`);

// Анализ источников
const adminPercent = (
  (stats.bySource.find((s) => s.source === 'ADMIN')?._count / stats.total) *
  100
).toFixed(1);
console.log(`Верифицированных: ${adminPercent}%`);

// Топ категории
console.log('Топ-5 категорий:');
stats.topCategories.forEach((cat, i) => {
  console.log(`${i + 1}. Категория ${cat.categoryId}: ${cat._count} продуктов`);
});
```

**Особенности:**

- **Производительность:** Все запросы выполняются параллельно
- **Период "недавно":** Жестко закодирован как 7 дней (можно вынести в параметр)
- **Только для админов:** Endpoint защищен admin guard
- **Агрегация:** Использует groupBy для эффективных подсчетов
- **Топ категории:** Ограничено 5-ю для краткости (можно параметризировать)

**Возможные улучшения:**

1. Добавить параметр периода для recentlyAdded
2. Добавить статистику по верификации (isVerified)
3. Добавить среднюю калорийность по категориям
4. Кэшировать результаты (TTL 1 час) для снижения нагрузки
