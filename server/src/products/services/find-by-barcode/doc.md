# Find By Barcode Service - Документация

## FindByBarcodeService

**Файл:** `find-by-barcode.service.ts`

**Назначение:** Поиск продукта по штрих-коду с проверкой прав доступа (используется для сканирования штрих-кодов).

### Метод: `execute(barcode: string, userId?: string)`

**Описание:**
Находит продукт по уникальному штрих-коду (EAN-13, UPC). Используется для функции сканирования штрих-кодов в мобильном приложении или веб-интерфейсе. Автоматически проверяет права доступа к приватным продуктам и загружает персональную цену пользователя.

**Параметры:**

- `barcode` (string) - Штрих-код продукта (EAN-13, UPC, или другой формат)
- `userId?` (string) - ID текущего пользователя (опционально)

**Возвращаемое значение:**
Объект продукта с полями:

- Все поля продукта (id, name, description, calories, proteins, fats, carbs, и т.д.)
- `category` - Полный объект категории
- `tags` - Массив связей тегов с полными объектами тегов
- `price` - Персональная цена пользователя (number или null)

**Логика работы:**

1. **Поиск по штрих-коду:**
   - Ищет продукт по уникальному полю `barcode`
   - Включает связанные данные: category, tags
   - Если userId передан, включает userPrices для этого пользователя

2. **Проверка существования:**
   - Если продукт не найден, выбрасывает `NotFoundException` с сообщением "Продукт с таким штрих-кодом не найден"

3. **Проверка прав доступа:**
   - Если продукт приватный (`isPublic: false`) И userId не совпадает с userId продукта
   - Выбрасывает `ForbiddenException`

4. **Обработка цены:**
   - Добавляет поле `price` из userPrices[0].price или null
   - Удаляет служебное поле `userPrices` из ответа

**Исключения:**

- `NotFoundException` - продукт с указанным штрих-кодом не найден
- `ForbiddenException` - доступ к приватному продукту запрещен (не владелец)

**Особенности:**

- **Уникальность штрих-кода:** Каждый штрих-код уникален на уровне БД (constraint)
- **Сканирование:** Используется в функции сканирования камерой телефона
- **Быстрый поиск:** Индекс на поле barcode для быстрого поиска
- **Контроль доступа:** Те же правила, что и для findOne

**Пример использования:**

```typescript
// Сканирование штрих-кода неавторизованным пользователем
const product = await findByBarcodeService.execute('1234567890123');

// Результат:
// {
//   id: 'product-uuid',
//   name: 'Куриная грудка',
//   barcode: '1234567890123',
//   isPublic: true,
//   category: { id, name, ... },
//   tags: [...],
//   price: null,
//   ...
// }
```

```typescript
// Сканирование авторизованным пользователем (с персональной ценой)
const product = await findByBarcodeService.execute(
  '1234567890123',
  'user-uuid',
);

// Результат:
// {
//   id: 'product-uuid',
//   name: 'Куриная грудка',
//   barcode: '1234567890123',
//   price: 450, // персональная цена пользователя
//   ...
// }
```

```typescript
// Обработка отсутствующего продукта
try {
  await findByBarcodeService.execute('9999999999999');
} catch (error) {
  // NotFoundException: Продукт с таким штрих-кодом не найден
  // Можно предложить пользователю добавить новый продукт
}
```

**Типичный сценарий использования:**

1. **Пользователь сканирует штрих-код** камерой телефона
2. **Приложение отправляет запрос** `GET /products/barcode/:barcode`
3. **Сервис ищет продукт:**
   - Если найден - показывает карточку продукта с КБЖУ и ценой
   - Если не найден - предлагает добавить новый продукт
4. **Пользователь добавляет в дневник** питания или в рецепт

**Связь с другими сервисами:**

- После нахождения продукта можно использовать `FindOneProductService` для полной информации
- Результат можно использовать для создания блюда/приема пищи
- Если продукт не найден, можно создать через `CreateProductService` с этим штрих-кодом
