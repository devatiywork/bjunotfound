# Calculate Services - Документация

## CalculateCaloriesService

**Файл:** `calculate-calories.service.ts`

**Назначение:** Расчет целевых калорий для достижения заданного веса за определенный период.

### Метод: `execute(userId: string, calculateCaloriesDto: CalculateCaloriesDto)`

**Описание:**
Рассчитывает целевое количество калорий в день для достижения целевого веса за указанное количество дней. Учитывает пол, возраст, рост, уровень активности и формулу расчета. Проверяет реалистичность цели и выдает предупреждения.

**Параметры:**

- `userId` (string) - ID пользователя
- `calculateCaloriesDto` (CalculateCaloriesDto):
  - `weight` (number) - Текущий вес (кг)
  - `targetWeight` (number) - Целевой вес (кг)
  - `days` (number) - Количество дней для достижения цели
  - `formula?` (FormulaType) - Формула расчета BMR (MIFFLIN_ST_JEOR или HARRIS_BENEDICT)

**Возвращаемое значение:**
Объект с результатами расчета:

- `bmr` (number) - Базальный метаболизм (ккал/день)
- `tdee` (number) - Общий расход энергии (ккал/день)
- `targetCalories` (number) - Целевые калории для достижения цели
- `dailyDeficit` (number) - Дневной дефицит/профицит калорий
- `isRealistic` (boolean) - Реалистична ли цель
- `warning?` (string) - Предупреждение о нереалистичной цели

**Логика работы:**

1. **Получение профиля пользователя:**
   - Загружает данные пользователя с уровнем активности
   - Выбрасывает `NotFoundException` если пользователь не найден

2. **Расчет возраста:**
   - Вычисляет возраст на основе даты рождения

3. **Определение формулы:**
   - Использует формулу из DTO или профиля пользователя
   - По умолчанию MIFFLIN_ST_JEOR

4. **Подготовка параметров:**
   - Вес из DTO
   - Рост, пол, возраст из профиля
   - Коэффициент активности из связанной таблицы

5. **Расчет калорий:**
   - Загружает настройки калорий из БД
   - Вызывает `calculateTargetCalories()` из utils
   - Проверяет безопасность цели (минимальные калории, максимальный дефицит)

**Исключения:**

- `NotFoundException` - пользователь не найден

**Особенности:**

- **Выбор формулы:** Миффлина-Сан Жеора (рекомендуется) или Харриса-Бенедикта
- **Безопасность:** Проверка минимальных калорий (1200 для женщин, 1500 для мужчин)
- **Реалистичность:** Предупреждения о слишком быстром темпе (макс. 1 кг/неделю для похудения)
- **Настройки из БД:** Все границы безопасности загружаются из таблицы `calorie_settings`

**Пример использования:**

```typescript
const result = await calculateCaloriesService.execute('user-uuid', {
  weight: 80,
  targetWeight: 75,
  days: 60,
  formula: 'MIFFLIN_ST_JEOR',
});

// Результат:
// {
//   bmr: 1650,
//   tdee: 2310,
//   targetCalories: 1893,
//   dailyDeficit: 417,
//   isRealistic: true
// }
```

## CalculateGoalPaceService

**Файл:** `calculate-goal-pace.service.ts`

**Назначение:** Генерация вариантов темпа достижения целевого веса с расчетом калорий и сроков для каждого варианта.

### Метод: `execute(userId: string, calculateGoalPaceDto: CalculateGoalPaceDto)`

**Описание:**
Создает несколько вариантов достижения цели с разными темпами (быстрый, средний, комфортный). Для каждого варианта рассчитывает требуемые калории, количество дней и дату окончания. Учитывает направление (похудение/набор) и предлагает разные стратегии.

**Параметры:**

- `userId` (string) - ID пользователя
- `calculateGoalPaceDto` (CalculateGoalPaceDto):
  - `targetWeight` (number) - Целевой вес (кг)
  - `startDate?` (string) - Дата начала (по умолчанию текущая дата)
  - `formula?` (FormulaType) - Формула расчета BMR

**Возвращаемое значение:**
Объект с вариантами:

```typescript
{
  currentWeight: number,
  targetWeight: number,
  startDate: Date,
  options: Array<{
    pace: string,           // Название темпа
    description: string,    // Описание
    targetCalories: number, // Целевые калории
    days: number,          // Количество дней
    endDate: Date,         // Дата окончания
    isRealistic: boolean,  // Реалистичность
    warning?: string       // Предупреждение
  }>
}
```

**Логика работы:**

1. **Получение профиля пользователя:**
   - Загружает данные с уровнем активности
   - Выбрасывает `NotFoundException` если не найден

2. **Получение текущего веса:**
   - Ищет последнюю запись веса
   - Выбрасывает `BadRequestException` если вес не найден

3. **Подготовка параметров:**
   - Вычисляет возраст
   - Определяет формулу
   - Устанавливает дату начала

4. **Определение направления:**
   - Похудение: currentWeight > targetWeight
   - Набор: currentWeight < targetWeight

5. **Загрузка конфигураций темпа:**
   - Для похудения: pace_very_fast, pace_fast, pace_moderate, pace_comfortable
   - Для набора: pace_gain_fast, pace_gain_moderate, pace_gain_comfortable

6. **Генерация вариантов:**
   - Вызывает `generateGoalPaceOptions()` из utils
   - Для каждого темпа рассчитывает калории, дни, дату окончания
   - Проверяет реалистичность каждого варианта

**Исключения:**

- `NotFoundException` - пользователь не найден
- `BadRequestException` - не найдена запись веса

**Особенности:**

- **Адаптивность:** Разные темпы для похудения и набора
- **Конфигурируемость:** Темпы загружаются из БД (можно менять без деплоя)
- **Поддержка шагов:** Учитывает дополнительные калории от активности (передается вес для расчета)
- **Реалистичность:** Каждый вариант проверяется на безопасность

**Пример использования:**

```typescript
const result = await calculateGoalPaceService.execute('user-uuid', {
  targetWeight: 75,
  startDate: '2026-01-10',
  formula: 'MIFFLIN_ST_JEOR',
});

// Результат:
// {
//   currentWeight: 80,
//   targetWeight: 75,
//   startDate: 2026-01-10,
//   options: [
//     {
//       pace: 'Быстрый темп',
//       description: '0.75 кг в неделю',
//       targetCalories: 1810,
//       days: 47,
//       endDate: 2026-02-26,
//       isRealistic: true
//     },
//     {
//       pace: 'Средний темп',
//       description: '0.5 кг в неделю',
//       targetCalories: 2060,
//       days: 70,
//       endDate: 2026-03-21,
//       isRealistic: true
//     },
//     {
//       pace: 'Комфортный темп',
//       description: '0.25 кг в неделю',
//       targetCalories: 2185,
//       days: 140,
//       endDate: 2026-05-30,
//       isRealistic: true
//     }
//   ]
// }
```

**Применение:**

- Помощь пользователю выбрать оптимальный темп
- Создание новой цели на основе выбранного варианта
- Сравнение разных стратегий достижения цели
