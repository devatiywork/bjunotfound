# Get Services - Документация

## GetUserGoalsService

**Файл:** `get-user-goals.service.ts`

**Назначение:** Получение всех целей пользователя (включая архивированные) с автоматическим обновлением статусов.

### Метод: `execute(userId: string)`

**Описание:**
Возвращает полный список целей пользователя. Перед выборкой автоматически обновляет статусы: проверяет просроченные цели и достигнутые цели на основе текущего веса.

**Параметры:**

- `userId` (string) - ID пользователя

**Возвращаемое значение:**
Массив целей, отсортированных по дате начала (от новых к старым).

**Логика работы:**

1. Обновляет просроченные цели (IN_PROGRESS → FAILED)
2. Получает последний вес
3. Обновляет статусы целей на основе текущего веса (IN_PROGRESS → COMPLETED)
4. Возвращает все цели без фильтрации

**Особенности:**

- **Lazy evaluation:** Статусы обновляются только при запросе
- **Включает архивированные:** Возвращает цели с `isArchived: true`
- **Сортировка:** По дате начала (DESC)

## GetActiveGoalsService

**Файл:** `get-active-goals.service.ts`

**Назначение:** Получение только активных (не завершенных и не архивированных) целей.

### Метод: `execute(userId: string)`

**Описание:**
Возвращает список активных целей пользователя. Автоматически обновляет статусы перед выборкой. Активные цели - это цели со статусом IN_PROGRESS, которые не архивированы.

**Параметры:**

- `userId` (string) - ID пользователя

**Возвращаемое значение:**
Массив целей с фильтром:

- `isActive: true`
- `isArchived: false`

**Логика работы:**

1. Обновляет просроченные цели
2. Получает последний вес
3. Обновляет статусы на основе текущего веса
4. Фильтрует цели: `isActive: true AND isArchived: false`

**Применение:**

- Отображение текущих активных целей в дашборде
- Проверка наличия активной цели перед созданием новой
- Мониторинг прогресса по активным целям

---

## GetAllGoalsService

**Файл:** `get-all-goals.service.ts`

**Назначение:** Получение всех целей пользователя, кроме архивированных.

### Метод: `execute(userId: string)`

**Описание:**
Возвращает все цели пользователя (активные, завершенные, проваленные), но исключает архивированные. Используется для отображения истории целей.

**Параметры:**

- `userId` (string) - ID пользователя

**Возвращаемое значение:**
Массив целей с фильтром:

- `isArchived: false`

**Логика работы:**

1. Обновляет просроченные цели
2. Получает последний вес
3. Обновляет статусы целей
4. Фильтрует: исключает архивированные

**Отличие от GetUserGoalsService:**

- `GetUserGoalsService` - ВСЕ цели (включая архивированные)
- `GetAllGoalsService` - все КРОМЕ архивированных

**Применение:**

- Отображение истории целей в профиле
- Статистика по завершенным/проваленным целям
- Выбор предыдущей цели для повторного использования

## GetArchivedGoalsService

**Файл:** `get-archived-goals.service.ts`

**Назначение:** Получение только архивированных (удаленных) целей.

### Метод: `execute(userId: string)`

**Описание:**
Возвращает список архивированных целей с минимальным набором полей. Используется для просмотра удаленных целей и возможности их восстановления.

**Параметры:**

- `userId` (string) - ID пользователя

**Возвращаемое значение:**
Массив целей с ограниченным набором полей:

- `id` - UUID цели
- `targetWeight` - Целевой вес
- `targetCalories` - Целевые калории
- `startDate` - Дата начала
- `endDate` - Дата окончания
- `isActive` - Активна ли (всегда false для архивированных)
- `status` - Статус (COMPLETED/FAILED/IN_PROGRESS)
- `isArchived` - Флаг архивации (всегда true)
- `deletedAt` - Дата архивирования
- `deletedBy` - ID пользователя, кто архивировал

**Логика работы:**

1. Фильтрует цели: `isArchived: true`
2. Сортирует по дате удаления (DESC)
3. Возвращает только необходимые поля (select)

**Особенности:**

- **Soft delete:** Цели не удаляются физически
- **Ограниченные поля:** Только основная информация для экономии трафика
- **Сортировка:** По дате архивирования (недавно удаленные первыми)

**Применение:**

- Корзина удаленных целей
- Восстановление случайно удаленной цели
- Аудит удаленных данных

## GetGoalByIdService

**Файл:** `get-goal-by-id.service.ts`

**Назначение:** Получение конкретной цели по ID с обновлением статуса.

### Метод: `execute(userId: string, goalId: string)`

**Описание:**
Возвращает полную информацию о конкретной цели. Перед выборкой обновляет статусы всех целей пользователя. Не возвращает архивированные цели.

**Параметры:**

- `userId` (string) - ID пользователя
- `goalId` (string) - UUID цели

**Возвращаемое значение:**
Объект цели со всеми полями или исключение.

**Логика работы:**

1. Обновляет просроченные цели
2. Получает последний вес
3. Обновляет статусы целей на основе веса
4. Ищет цель с фильтром: `id = goalId AND userId = userId AND isArchived = false`
5. Выбрасывает `NotFoundException` если не найдена

**Исключения:**

- `NotFoundException` - цель не найдена, архивирована или принадлежит другому пользователю

**Особенности:**

- **Проверка владельца:** Пользователь может получить только свою цель
- **Исключение архивированных:** Архивированные цели недоступны через этот метод
- **Актуальный статус:** Гарантированно актуальный статус после обновления

**Применение:**

- Просмотр детальной информации о цели
- Проверка существования цели перед операциями
- Получение цели для редактирования
