# Archive Services - Документация

## ArchiveGoalService

**Файл:** `archive-goal.service.ts`

**Назначение:** Мягкое удаление (архивирование) цели.

### Метод: `execute(goalId: string, userId: string)`

**Описание:**
Архивирует цель вместо физического удаления. Устанавливает флаги `isArchived: true`, `isActive: false` и записывает метаданные удаления. Архивированные цели можно восстановить.

**Параметры:**

- `goalId` (string) - UUID цели для архивирования
- `userId` (string) - ID текущего пользователя

**Возвращаемое значение:**
Архивированная цель с обновленными полями:

- `isArchived: true`
- `deletedAt: Date` - текущая дата
- `deletedBy: string` - ID пользователя
- `isActive: false` - деактивирована

**Логика работы:**

1. **Проверка существования:**
   - Ищет цель по ID
   - Выбрасывает `NotFoundException` если не найдена

2. **Проверка прав:**
   - Сравнивает `goal.userId` с `userId`
   - Выбрасывает `NotFoundException` если не совпадает

3. **Архивирование:**
   - Обновляет флаги архивации
   - Записывает метаданные (дата и автор удаления)
   - Деактивирует цель

**Исключения:**

- `NotFoundException` - цель не найдена
- `NotFoundException` - у пользователя нет прав для удаления (сообщение "У вас нет прав для удаления этой цели")

**Особенности:**

- **Soft delete:** Данные сохраняются в БД
- **Возможность восстановления:** Через RestoreGoalService
- **Автоматическая деактивация:** `isActive` устанавливается в false
- **Метаданные:** Записывается кто и когда удалил

**Пример использования:**

```typescript
// Архивирование цели
const archived = await archiveGoalService.execute('goal-uuid', 'user-uuid');

// Результат:
// {
//   id: 'goal-uuid',
//   ...остальные поля,
//   isArchived: true,
//   deletedAt: Date,
//   deletedBy: 'user-uuid',
//   isActive: false
// }
```

**Применение:**

- Удаление ненужной цели без потери истории
- Очистка списка активных целей
- Временное скрытие цели с возможностью восстановления

## RestoreGoalService

**Файл:** `restore-goal.service.ts`

**Назначение:** Восстановление архивированной цели.

### Метод: `execute(goalId: string, userId: string)`

**Описание:**
Восстанавливает архивированную цель. Снимает флаг архивации и очищает метаданные удаления. Цель становится доступной в обычных списках, но остается неактивной - пользователь должен активировать ее вручную.

**Параметры:**

- `goalId` (string) - UUID цели для восстановления
- `userId` (string) - ID текущего пользователя

**Возвращаемое значение:**
Восстановленная цель с обновленными полями:

- `isArchived: false`
- `deletedAt: null`
- `deletedBy: null`
- `isActive` - остается без изменений (обычно false)

**Логика работы:**

1. **Проверка существования:**
   - Ищет цель по ID
   - Выбрасывает `NotFoundException` если не найдена

2. **Проверка архивации:**
   - Проверяет флаг `isArchived`
   - Выбрасывает `BadRequestException` если цель не архивирована

3. **Проверка прав:**
   - Сравнивает `goal.userId` с `userId`
   - Выбрасывает `NotFoundException` если не совпадает

4. **Восстановление:**
   - Снимает флаг архивации
   - Очищает метаданные удаления
   - НЕ активирует автоматически

**Исключения:**

- `NotFoundException` - цель не найдена
- `BadRequestException` - цель не архивирована (нечего восстанавливать)
- `NotFoundException` - у пользователя нет прав для восстановления

**Особенности:**

- **Ручная активация:** `isActive` остается false - пользователь должен активировать отдельно
- **Очистка метаданных:** deletedAt и deletedBy обнуляются
- **Проверка состояния:** Нельзя восстановить неархивированную цель

**Пример использования:**

```typescript
// Восстановление архивированной цели
const restored = await restoreGoalService.execute('goal-uuid', 'user-uuid');

// Результат:
// {
//   id: 'goal-uuid',
//   ...остальные поля,
//   isArchived: false,
//   deletedAt: null,
//   deletedBy: null,
//   isActive: false  // требуется ручная активация
// }
```

**Попытка восстановить неархивированную цель:**

```typescript
try {
  await restoreGoalService.execute('active-goal-uuid', 'user-uuid');
} catch (error) {
  // BadRequestException: Цель не архивирована
}
```

**Применение:**

- Восстановление случайно удаленной цели
- Возврат цели из корзины
- Повторное использование старой цели

**Workflow восстановления:**

1. Пользователь восстанавливает цель через RestoreGoalService
2. Цель появляется в списке неактивных целей
3. Пользователь проверяет параметры цели (даты, калории)
4. При необходимости обновляет через UpdateGoalService
5. Активирует цель через UpdateGoalService (`isActive: true`)
