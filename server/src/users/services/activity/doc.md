# Activity Services - Документация

## GetActivityLevelsService

**Файл:** `get-activity-levels.service.ts`

**Назначение:** Получение списка всех доступных уровней физической активности.

### Метод: `execute()`

**Описание:**
Возвращает все предопределенные уровни активности из базы данных, отсортированные по коэффициенту (от наименьшего к наибольшему).

**Параметры:**
Метод не принимает параметров.

**Возвращаемое значение:**
Массив объектов уровней активности со следующими полями:

- `id` (string) - Уникальный идентификатор уровня
- `name` (string) - Название уровня (например, "Сидячий образ жизни", "Легкая активность")
- `description` (string) - Описание уровня активности
- `coefficient` (number) - Коэффициент для расчета TDEE (например, 1.2, 1.375, 1.55, 1.725, 1.9)

**Сортировка:**
Результаты отсортированы по возрастанию коэффициента (от минимальной к максимальной активности).

**Использование:**
Уровни активности используются для:

1. Расчета дневной нормы калорий (TDEE = BMR × coefficient)
2. Заполнения профиля пользователя при регистрации/обновлении
3. Выбора пользователем своего уровня активности в интерфейсе

**Стандартные уровни:**

1. **Сидячий образ жизни** (1.2) - минимальная активность
2. **Легкая активность** (1.375) - тренировки 1-3 раза в неделю
3. **Умеренная активность** (1.55) - тренировки 3-5 раз в неделю
4. **Высокая активность** (1.725) - тренировки 6-7 раз в неделю
5. **Экстремальная активность** (1.9) - тяжелые тренировки дважды в день

**Пример использования:**

```typescript
const levels = await getActivityLevelsService.execute();
// [
//   { id: '...', name: 'Сидячий образ жизни', description: '...', coefficient: 1.2 },
//   { id: '...', name: 'Легкая активность', description: '...', coefficient: 1.375 },
//   { id: '...', name: 'Умеренная активность', description: '...', coefficient: 1.55 },
//   { id: '...', name: 'Высокая активность', description: '...', coefficient: 1.725 },
//   { id: '...', name: 'Экстремальная активность', description: '...', coefficient: 1.9 }
// ]
```

**Пример использования в профиле:**

```typescript
// Получить уровни для выпадающего списка
const levels = await getActivityLevelsService.execute();

// Пользователь выбирает уровень
await updateProfileService.execute('user-id', {
  activityLevelId: levels[2].id, // Умеренная активность
});
```

**Связь с расчетом калорий:**

```typescript
// BMR (базальный метаболизм) рассчитывается по формуле
const bmr = calculateBMR(weight, height, age, gender, formulaType);

// TDEE (дневная норма калорий) = BMR × coefficient
const tdee = bmr * activityLevel.coefficient;
```
