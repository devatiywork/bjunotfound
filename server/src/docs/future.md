# Планы развития бекенда — приоритеты и идеи

Документ описывает приоритетные задачи для бекенда и идеи на будущее.

## Приоритетные задачи

### Система планирования рациона

- Календарь/таймлайн: привязка блюд и продуктов к дате и времени приёма пищи (завтрак/обед/ужин/перекус).
- Планирование на день/неделю/месяц, API для клиента календаря.

### Учет потребленных калорий

- Отметка `isEaten` для планируемых позиций, сбор фактического потребления, агрегированные показатели за день/неделю.

### Таблица тренировок

- Создать сущность `workouts` для записи тренировок и активности: тип тренировки, дата/время, шаги, потраченные калории, длительность, дополнительные метрики.
- Предусмотреть связь с пользователем и возможность агрегации по дням/неделям.

## Идеи на будущее (может быть когда-нибудь)

1. Оповещения в Telegram
   - Исследовать возможность уведомлений и напоминаний через бота/вебхуки.

2. Мобильное приложение
   - Планирование мобильного клиента: синхронизация с API, offline-режим, push-уведомления.

3. Повышение безопасности, 2FA и сторонняя регистрация
   - Двухфакторная аутентификация (по почте или TOTP).
   - Регистрация/логин через OAuth-провайдеров (Google, Apple и т.д.).

4. Система достижений
   - Награды и бейджи за прогресс (последовательность дней, достигнутые цели и т.п.).

5. Автоматический расчёт ИМТ
   - Автоматический расчёт и история ИМТ на основе роста и записей веса, классификация по ВОЗ.

6. Советы от нейросети и чат
   - Интеграция с LLM для персонализированных советов, диалоговый интерфейс и рекомендации.

7. Генерация блюд нейросетью
   - Генерация рецептов и планов питания с учётом ограничений по калориям и предпочтений пользователя.

8. Рецепты для блюд (план)
   - Возможность прикреплять к блюду рецепт: пошаговые инструкции, фото шагов, время на шаг, порции.
