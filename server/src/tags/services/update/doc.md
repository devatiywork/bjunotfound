# Update Tag Service - Документация

## UpdateTagService

**Файл:** `update-tag.service.ts`

**Назначение:** Обновление названия существующего тега с проверкой уникальности.

### Метод: `execute(id: string, data: UpdateTagDto)`

**Описание:**
Обновляет название тега. Проверяет существование тега и уникальность нового имени. Используется администраторами для исправления опечаток или переименования тегов.

**Параметры:**

- `id` (string) - UUID тега для обновления
- `data` (UpdateTagDto) - Данные для обновления:
  - `name?` (string) - Новое название тега (опционально)

**Возвращаемое значение:**
Обновленный тег с полями:

- `id` (string) - UUID тега
- `name` (string) - Обновленное название
- `createdAt` (Date) - Дата создания (не меняется)
- `updatedAt` (Date) - Дата обновления (обновляется автоматически)

**Логика работы:**

1. **Проверка существования:**
   - Ищет тег по ID
   - Выбрасывает `NotFoundException` если не найден

2. **Проверка уникальности (если имя меняется):**
   - Если новое имя отличается от текущего
   - Проверяет, не занято ли новое имя другим тегом
   - Выбрасывает `BadRequestException` если найден дубликат

3. **Обновление:**
   - Обновляет запись в БД
   - Возвращает обновленный тег

**Исключения:**

- `NotFoundException` - тег с указанным ID не найден
- `BadRequestException` - тег с таким именем уже существует

**Особенности:**

- **Только для админов:** Endpoint защищен admin guard
- **Частичное обновление:** Все поля опциональны
- **Проверка только при изменении:** Уникальность проверяется только если имя действительно меняется
- **Автообновление даты:** updatedAt обновляется автоматически

**Пример использования:**

```typescript
// Переименование тега
const updated = await updateTagService.execute('tag-uuid', {
  name: 'Высокопротеиновое', // исправляем с "Высокобелковое"
});

// Результат:
// {
//   id: 'tag-uuid',
//   name: 'Высокопротеиновое',
//   createdAt: Date (старая),
//   updatedAt: Date (обновлена)
// }
```

**Попытка использовать занятое имя:**

```typescript
try {
  await updateTagService.execute('tag-uuid', {
    name: 'Веганское', // уже существует
  });
} catch (error) {
  // BadRequestException: Тег с таким именем уже существует
}
```

**Обновление несуществующего тега:**

```typescript
try {
  await updateTagService.execute('non-existent-uuid', {
    name: 'Новое название',
  });
} catch (error) {
  // NotFoundException: Тег не найден
}
```

**Применение:**

- Исправление опечаток в названиях тегов
- Переименование тегов для лучшей понятности
- Унификация терминологии
- Локализация названий тегов
