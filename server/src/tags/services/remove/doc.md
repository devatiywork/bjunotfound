# Remove Tag Service - Документация

## RemoveTagService

**Файл:** `remove-tag.service.ts`

**Назначение:** Удаление тега с защитой от удаления используемых тегов.

### Метод: `execute(id: string)`

**Описание:**
Удаляет тег из базы данных. Проверяет, что тег не используется ни одним продуктом перед удалением. Используется администраторами для очистки неиспользуемых или ошибочно созданных тегов.

**Параметры:**

- `id` (string) - UUID тега для удаления

**Возвращаемое значение:**
Объект с сообщением:

```typescript
{
  message: 'Тег успешно удален';
}
```

**Логика работы:**

1. **Проверка существования:**
   - Ищет тег по ID
   - Включает счетчик привязанных продуктов
   - Выбрасывает `NotFoundException` если тег не найден

2. **Проверка использования:**
   - Проверяет, есть ли продукты с этим тегом
   - Выбрасывает `BadRequestException` если тег используется
   - Указывает точное количество привязанных продуктов в сообщении

3. **Удаление:**
   - Если проверки пройдены, удаляет тег из БД
   - Возвращает сообщение об успехе

**Исключения:**

- `NotFoundException` - тег с указанным ID не найден
- `BadRequestException` - невозможно удалить тег, так как к нему привязаны продукты (с указанием количества)

**Особенности:**

- **Только для админов:** Endpoint защищен admin guard
- **Защита от случайного удаления:** Нельзя удалить используемый тег
- **Информативная ошибка:** Сообщение содержит количество привязанных продуктов
- **Необратимость:** Удаление необратимо (hard delete)

**Влияние на связанные данные:**

1. **ProductTag:**
   - Связи тега с продуктами должны быть удалены вручную до удаления тега
   - Автоматическое каскадное удаление НЕ применяется для защиты данных

2. **Продукты:**
   - Продукты не затрагиваются (только связи через ProductTag)

**Пример использования:**

```typescript
// Успешное удаление неиспользуемого тега
const result = await removeTagService.execute('unused-tag-uuid');

// Результат:
// { message: 'Тег успешно удален' }
```

**Попытка удалить используемый тег:**

```typescript
try {
  await removeTagService.execute('popular-tag-uuid');
} catch (error) {
  // BadRequestException: Невозможно удалить тег: к нему привязано 89 продуктов
}
```

**Удаление несуществующего тега:**

```typescript
try {
  await removeTagService.execute('non-existent-uuid');
} catch (error) {
  // NotFoundException: Тег не найден
}
```

**Рекомендации по использованию:**

1. **Перед удалением:** Проверить через `GET /tags/:id`, сколько продуктов используют тег
2. **Если тег используется:**
   - Создать новый правильный тег
   - Переназначить продукты на новый тег через batch update
   - Удалить старый тег
3. **Альтернатива:** Переименовать тег через `PATCH /tags/:id` вместо удаления
4. **Для админов:** Удалять с осторожностью, особенно популярные теги

**Типичный сценарий замены тега:**

```typescript
// 1. Создать новый тег
const newTag = await createTagService.execute({ name: 'Правильное название' });

// 2. Обновить все продукты со старым тегом (в цикле или batch)
// ... обновление ProductTag связей ...

// 3. Удалить старый тег (теперь неиспользуемый)
await removeTagService.execute('old-tag-uuid');
```
