# Find One Tag Service - Документация

## FindOneTagService

**Файл:** `find-one-tag.service.ts`

**Назначение:** Получение детальной информации о конкретном теге по ID.

### Метод: `execute(id: string)`

**Описание:**
Возвращает полную информацию о теге, включая количество связанных продуктов. Используется для просмотра деталей тега и проверки его существования перед операциями.

**Параметры:**

- `id` (string) - UUID тега

**Возвращаемое значение:**
Объект тега с полями:

- `id` (string) - UUID тега
- `name` (string) - Название тега
- `createdAt` (Date) - Дата создания
- `updatedAt` (Date) - Дата обновления
- `_count` (object) - Объект со счетчиками:
  - `products` (number) - Количество продуктов с этим тегом

**Логика работы:**

1. **Запрос тега:**
   - Ищет тег по ID
   - Включает счетчик привязанных продуктов

2. **Проверка существования:**
   - Если тег не найден, выбрасывает `NotFoundException`

**Исключения:**

- `NotFoundException` - тег с указанным ID не найден

**Особенности:**

- **Публичный доступ:** Endpoint доступен без авторизации
- **Счетчик продуктов:** Показывает, насколько популярен тег
- **Быстрая проверка:** Используется перед удалением/обновлением

**Пример использования:**

```typescript
const tag = await findOneTagService.execute('tag-uuid');

// Результат:
// {
//   id: 'tag-uuid',
//   name: 'Высокобелковое',
//   createdAt: Date,
//   updatedAt: Date,
//   _count: { products: 89 }
// }
```

**Обработка отсутствующего тега:**

```typescript
try {
  await findOneTagService.execute('non-existent-uuid');
} catch (error) {
  // NotFoundException: Тег не найден
}
```

**Применение:**

- Просмотр детальной информации о теге
- Проверка существования тега перед операциями
- Отображение статистики по конкретному тегу
- Валидация ID тега в формах
