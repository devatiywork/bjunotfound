# Find All Tags Service - Документация

## FindAllTagsService

**Файл:** `find-all-tags.service.ts`

**Назначение:** Получение списка всех тегов с подсчетом привязанных продуктов.

### Метод: `execute()`

**Описание:**
Возвращает полный список тегов, отсортированный по названию в алфавитном порядке. Для каждого тега включает количество связанных продуктов. Используется для отображения списка доступных тегов при создании/редактировании продуктов и для фильтрации.

**Параметры:**
Метод не принимает параметров.

**Возвращаемое значение:**
Массив тегов с полями:

- `id` (string) - UUID тега
- `name` (string) - Название тега
- `createdAt` (Date) - Дата создания
- `updatedAt` (Date) - Дата обновления
- `_count` (object) - Объект со счетчиками:
  - `products` (number) - Количество продуктов с этим тегом

**Логика работы:**

1. **Запрос тегов:**
   - Получает все теги из БД
   - Включает счетчик привязанных продуктов
   - Сортирует по имени в алфавитном порядке

**Особенности:**

- **Публичный доступ:** Endpoint доступен без авторизации
- **Счетчик продуктов:** Помогает оценить популярность тега
- **Сортировка:** Всегда алфавитная для удобства поиска
- **Полный список:** Нет пагинации (теги - ограниченный набор)

**Пример использования:**

```typescript
const tags = await findAllTagsService.execute();

// Результат:
// [

//   },
//   {
//     id: 'uuid-2',
//     name: 'Веганское',

//     name: 'Высокобелковое',
//     createdAt: Date,
//     updatedAt: Date,
```

**Использование в UI:**

```typescript
// Отображение списка тегов с количеством
const tags = await findAllTagsService.execute();
tags.forEach((tag) => {
  console.log(`${tag.name} (${tag._count.products} продуктов)`);
});

// Фильтр продуктов по тегам
const tagIds = tags
  .filter((tag) => selectedTagNames.includes(tag.name))
  .map((tag) => tag.id);
```

**Применение:**

- Выбор тегов при создании продукта
- Фильтрация продуктов в каталоге
- Отображение статистики использования тегов
- Админ-панель для управления тегами
