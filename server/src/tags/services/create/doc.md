# Create Tag Service - Документация

## CreateTagService

**Файл:** `create-tag.service.ts`

**Назначение:** Создание нового тега для продуктов с проверкой уникальности названия.

### Метод: `execute(data: CreateTagDto)`

**Описание:**
Создает новый тег для категоризации продуктов питания. Проверяет уникальность имени перед созданием. Используется администраторами для расширения системы тегирования.

**Параметры:**

- `data` (CreateTagDto) - Данные нового тега:
  - `name` (string) - Название тега (уникальное, обязательное)

**Возвращаемое значение:**
Созданный тег с полями:

- `id` (string) - UUID тега
- `name` (string) - Название тега
- `createdAt` (Date) - Дата создания
- `updatedAt` (Date) - Дата обновления

**Логика работы:**

1. **Проверка уникальности:**
   - Ищет тег с таким же именем в БД
   - Выбрасывает `BadRequestException` если найден дубликат

2. **Создание тега:**
   - Создает новую запись в таблице `tags`
   - Возвращает созданный тег

**Исключения:**

- `BadRequestException` - тег с таким именем уже существует

**Особенности:**

- **Уникальность имени:** Глобальная проверка на уровне сервиса + unique constraint в БД
- **Только для админов:** Endpoint защищен admin guard
- **Регистр:** Имя чувствительно к регистру

**Пример использования:**

```typescript
const tag = await createTagService.execute({
  name: 'Высокобелковое',
});

// Результат:
// {
//   id: 'uuid',
//   name: 'Высокобелковое',
//   createdAt: Date,
//   updatedAt: Date
// }
```

**Попытка создания дубликата:**

```typescript
try {
  await createTagService.execute({
    name: 'Высокобелковое', // уже существует
  });
} catch (error) {
  // BadRequestException: Тег с таким именем уже существует
}
```
